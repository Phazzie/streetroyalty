# Street Royalty project rules

This repository is Street Royalty, an existing streetwear site. Production deploys from
`main`.

- Never replace this app, its home page, its theme, or its brand assets with a different
  app. A new product idea goes in its own repository, however the request is worded.
- Read `PRODUCT.md` before deciding what a request means here.
- Change `main` only through a pull request. Never push to it directly.
